# DirtyFrag Archive

Preserved from the Ubuntu LPE hunt so the PoC material is not lost.

- `upstream/`: local clone of `https://github.com/V4bel/dirtyfrag` at commit `aab16fc`, copied without its `.git` directory.
- `ubuntu-stock-busybox/dirtyfrag_busybox_aarch64.c`: Ubuntu stock/busybox AppArmor path variant used during the hunt.
- `ubuntu-stock-busybox/dirtyfrag-busybox-test.sh`: QEMU guest runner for the busybox/aarch64 variant.
- `ubuntu-stock-busybox/dirtyfrag-busybox-aarch64`: compiled aarch64 test binary from the hunt workspace.
- `ubuntu-stock-busybox/qemu-serial-dirtyfrag-busybox-aarch64.log`: serial log captured during that probe.
